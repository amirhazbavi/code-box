Everything in one cockpit

Less context switching.
More building.

CodeBox combines useful everyday tools instead of pretending every runtime ships inside one app. Install the toolchains you need; the editor can open almost any text-based project file.

⌨

Multi-language editor

Tabbed editing, file explorer, syntax highlighting through Pygments, search/replace and reusable project files.

▶

Terminal & runners

Run common languages through installed runtimes and compilers. Compiler output and app logs appear in the terminal panel.

⌘

GitHub workspace

Connect with a token or OAuth, browse repositories, create repos, upload files and maintain local project snapshots.

✦

AI Lab

Use your own Gemini or Groq API key. Credentials are entered at runtime, not hardcoded in the source.

⌂

Local vault

Organize projects, save snapshots and keep your workspace files on your computer unless you explicitly upload them.

⬆

Learn & level up

Lessons, XP, achievements and progress tracking to make consistent practice feel less like homework.
