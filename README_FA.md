# CodeBox Nexus Studio | نسخهٔ پیشرفته

این بسته شامل برنامهٔ دسکتاپ، وب‌سایت دانلود، سرور مشترک حساب‌ها، نسخه‌های Free و Plus، لوگوی داخلی، و اسکریپت ساخت EXE برای ویندوز است. تمام نوشته‌های رابط کاربری برنامه و وب‌سایت انگلیسی هستند.

## محتویات

- `CodeBox_Free.py` — برنامهٔ دسکتاپ رایگان
- `CodeBox_Plus.py` — برنامهٔ Plus؛ قابلیت‌های پولی فقط برای حسابی فعال می‌شوند که سرور آن را `plus` تأیید کند
- `CodeBox_Website.html` — یک فایل HTML برای وب‌سایت دانلود، معرفی قابلیت‌ها، ورود، ثبت‌نام و قفل دانلود Plus
- `CodeBox_Server.py` — سرور حساب‌ها و وب‌سایت با SQLite؛ برای ورود مشترک وب و دسکتاپ لازم است
- `Run_CodeBox_Server.bat` — نصب وابستگی‌های سرور و اجرای آن
- `Build_CodeBox_EXE.bat` — ساخت دو فایل `CodeBox_Free.exe` و `CodeBox_Plus.exe`
- `Activate_Plus_Account.py` — ابزار مدیر برای فعال/غیرفعال کردن دستی اشتراک Plus
- `requirements_*.txt` — وابستگی‌ها
- `downloads/` — فایل‌هایی که وب‌سایت اجازهٔ دانلودشان را می‌دهد
- `CodeBox.ico` — آیکن ویندوز؛ لوگوی برنامه نیز داخل سورس رسم می‌شود

## اجرای محلی روی Windows

۱. ZIP را Extract کن.

۲. روی `Run_CodeBox_Server.bat` دوبار کلیک کن. بار اول وابستگی‌های سرور نصب می‌شوند. این پنجره را باز نگه دار.

اگر می‌خواهی Plus را دستی فعال کنی یا OAuth/کد ایمیل را تنظیم کنی، از `.env.example` یک کپی به نام `.env` بساز و مقادیر محرمانهٔ واقعی خودت را در آن قرار بده؛ مقدار نمونه را همان‌طور رها نکن. سرور فایل `.env` را هنگام شروع می‌خواند.

۳. در مرورگر برو به:

`http://127.0.0.1:8765`

۴. ابتدا روی سایت حساب بساز و وارد شو. دانلود رایگان بعد از ورود فعال است. برای استفاده از برنامهٔ دسکتاپ نیز باید همان سرور روشن باشد و با همان حساب وارد شوی.

۵. برای ساخت فایل‌های اجرایی، `Build_CodeBox_EXE.bat` را اجرا کن. بعد از پایان ساخت، فایل‌ها در `dist` ایجاد می‌شوند و اسکریپت آن‌ها را به پوشهٔ `downloads` کپی می‌کند. از آن پس سایت EXE دانلود می‌کند؛ تا قبل از ساخت EXE، از فایل منبع Python استفاده می‌کند.

اگر Python Launcher (`py`) نداری، اسکریپت‌ها مسیر رایج نصب Python در `%LOCALAPPDATA%\Python\pythoncore-3.14-64\python.exe` را هم بررسی می‌کنند. برای مسیر غیرمعمول، متغیر محیطی `CODEBOX_PYTHON` را برابر مسیر کامل `python.exe` قرار بده.

## ورود و حساب‌ها

- ورود با ایمیل و رمز عبور و ساخت حساب از ابتدا فعال است.
- ورود با کد ایمیل ۶ رقمی بعد از تنظیم SMTP سرور فعال می‌شود. کد ۵ دقیقه اعتبار دارد و تعداد تلاش‌ها محدود است.
- ورود با GitHub و Google بعد از ثبت OAuth Client ID/Secret در متغیرهای محیطی و تعیین callback URLs فعال می‌شود.
- سایت و برنامه از یک پایگاه دادهٔ سرور استفاده می‌کنند. ورود محلی داخل `localStorage` یا نمایشی نیست.

### تنظیم OAuth در حالت محلی

Callback هر دو سرویس را مطابق URL تنظیم‌شده در پنل توسعه‌دهنده وارد کن:

- GitHub: `http://127.0.0.1:8765/auth/github/callback`
- Google: `http://127.0.0.1:8765/auth/google/callback`

سپس متغیرهای محیطی `CODEBOX_GITHUB_CLIENT_ID`, `CODEBOX_GITHUB_CLIENT_SECRET`, `CODEBOX_GOOGLE_CLIENT_ID`, و `CODEBOX_GOOGLE_CLIENT_SECRET` را تنظیم کن و سرور را دوباره اجرا کن. برای OAuth در سایت عمومی باید callback روی دامنهٔ HTTPS واقعی باشد.

### کد ورود ایمیلی

متغیرهای `CODEBOX_SMTP_HOST`, `CODEBOX_SMTP_PORT`, `CODEBOX_SMTP_USER`, `CODEBOX_SMTP_PASSWORD`, و `CODEBOX_SMTP_FROM` را تنظیم کن. اگر Gmail استفاده می‌کنی، از App Password استفاده کن، نه رمز اصلی صندوق ایمیل.

## قفل Plus

- سایت دانلود Plus را سمت سرور قفل می‌کند. تغییر متن یا دکمهٔ HTML به‌تنهایی قفل واقعی نمی‌سازد؛ این پروژه دانلود را در سرور بررسی می‌کند.
- پرداخت آنلاین هنوز به درگاه پرداخت و webhook نیاز دارد. فعلاً فعال‌سازی Plus دستی است.
- پیش از اجرای سرور، در فایل `.env` مقدار `CODEBOX_ADMIN_KEY` را به یک مقدار تصادفی و محرمانه تنظیم کن. سپس اجرا کن:

`python Activate_Plus_Account.py`

این ابزار کلید مدیر را در صورت نیاز به‌صورت پنهان می‌پرسد. حساب باید قبلاً ثبت شده باشد. کاربر باید در برنامه خارج شود و دوباره وارد شود تا پلن تازه اعمال شود.

## استقرار روی اینترنت

**فایل HTML به‌تنهایی نمی‌تواند احراز هویت یا قفل Plus امن ایجاد کند.** برای وب‌سایت عمومی باید `CodeBox_Server.py` روی هاستی اجرا شود که Python/Flask را پشتیبانی می‌کند. فقط فایل HTML را در هاست استاتیک قرار نده، چون API، حساب‌ها و دانلود امن آن کار نمی‌کند.

در سرور عمومی:

- `CODEBOX_SECRET_KEY` را روی یک کلید تصادفی قوی و دائمی قرار بده.
- `CODEBOX_ADMIN_KEY` را جداگانه و قوی تنظیم کن.
- `CODEBOX_PUBLIC_URL` را برابر URL عمومی HTTPS قرار بده.
- `CODEBOX_HOST=0.0.0.0` را فقط پشت reverse proxy/هاست مناسب تنظیم کن.
- `CODEBOX_COOKIE_SECURE=1` را برای HTTPS روشن کن.
- فایل SQLite و پوشهٔ `downloads` باید روی فضای ذخیره‌سازی پایدار باشند.
- سرور توسعهٔ Flask را مستقیم و بدون HTTPS در معرض اینترنت قرار نده.
- برای اجرای production از سرویس WSGI و reverse proxy با HTTPS استفاده کن.
- هیچ API key، توکن GitHub، رمز SMTP یا کلید OAuth واقعی را در سورس، ZIP، سایت یا مخزن عمومی قرار نده.

## پوشش زبان‌ها

ویرایشگر با Pygments مجموعهٔ بزرگی از زبان‌ها و فرمت‌ها را رنگ‌آمیزی می‌کند. اجرای خودکار برای چند زبان رایج اضافه شده، اما هر زبان به runtime یا compiler خودش نیاز دارد؛ نصب همهٔ زبان‌ها داخل یک برنامهٔ Python واقع‌بینانه نیست. دستورات ترمینال به مجوزهای سیستم کاربر اجرا می‌شوند و sandbox امنیتی نیستند؛ فقط کدی را اجرا کن که به آن اعتماد داری.

## محدودیت‌هایی که صادقانه باید بدانی

- این بسته سورس و اسکریپت‌های ساخت را دارد؛ EXE از پیش‌کامپایل‌شده داخل ZIP نیست. اسکریپت Build روی ویندوز EXE می‌سازد.
- محیط ساخت این فایل‌ها PySide6 و Flask نصب‌شده نداشت و دسترسی شبکه برای نصب بسته‌ها نیز در دسترس نبود؛ بنابراین بررسی نحوی Python انجام شده، اما اجرای کامل GUI/سرور در همین محیط تأیید نشده است.
- پرداخت آنلاین و مدیریت خودکار تمدید/لغو اشتراک هنوز وصل نیست. مدیر فعلاً پلن را دستی تغییر می‌دهد.
- کارکرد OAuth وابسته به Client ID/Secret و تنظیم دقیق callback در پنل هر سرویس است.
